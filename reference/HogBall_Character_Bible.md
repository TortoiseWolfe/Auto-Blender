# HogBall Character Bible
## Fantasy Football Game - "Scrum" the Pig Mascot Evolution Guide

---

## Overview

**Game Name:** HogBall

**Game Concept:** A fantasy football game where a sentient pig IS the ball. The pig acts as a third faction, creating chaos that affects all players equally.

**Mascot Name:** Scrum

**Evolution System:** Scrum evolves from a cute baby piglet to a fierce wild boar as players level up, with behavior becoming increasingly chaotic and retaliatory.

---

## Character Consistency Spec

### IMMUTABLE TRAITS (Never Change Across All Evolutions)

These elements MUST appear in every version to maintain character identity:

| Trait | Specification |
|-------|---------------|
| Body silhouette | Football-shaped (pointed at both ends, widest in middle) |
| Lacing | White football stitching running vertically along spine/back |
| Eye position | Close together, positioned near/above the snout |
| Eye color | Golden amber/yellow (hex #D4A017) with black pupil |
| Snout | Large with two prominent oval nostrils |
| Tail | Curly (gets thicker/longer but always curly) |
| Hooves | Same shape throughout (scale up, don't redesign) |
| Motion lines | On LEFT side suggesting speed/chaos |
| Badge format | Hexagonal shield, gold/black border, green field, "HOGBALL" banner |

### EVOLUTION VARIABLES

| Trait | Level 1 (Baby) | Level 2 (Adolescent) | Level 3 (Young Hog) | Level 4 (Wild Boar) |
|-------|----------------|----------------------|---------------------|---------------------|
| **Base color** | Bubblegum pink #FFB6C1 | Dusty pink #D4A5A5 with brown spots | Reddish brown #A0522D | Dark leather brown #8B4513 |
| **Skin texture** | Smooth, shiny | Slightly textured | Coarse, some bristles | Heavy bristles, scars |
| **Expression** | Innocent, confused | Mischievous, smirking | Determined, cunning | Aggressive, fierce |
| **Ears** | Small, floppy, down | Medium, slightly up | Large, pointed, alert | Battle-torn, scarred |
| **Tusks** | None | Tiny nubs barely visible | Small but visible | Full curved tusks |
| **Eyebrows** | None/soft | Slight furrow | Pronounced | Heavy, angry V-shape |
| **Body mass** | Round, soft | Slightly muscular | Stocky, solid | Massive, armored look |
| **Hooves** | Pink, tiny | Darker pink | Grey | Black/dark with mud |

### BEHAVIOR CORRELATION

| Level | Form | In-Game Behavior |
|-------|------|------------------|
| 1-10 | Baby Pig (Scrum) | Mostly cooperative, occasional squirms |
| 11-25 | Adolescent (Scrum) | More cunning, starts to resist |
| 26-40 | Young Hog (Scrum) | Active evasion, environmental awareness |
| 41+ | Wild Boar (Scrum) | Full chaos mode, retaliates when tackled (cucco-style) |

## Pro Tips for AI Image Generation

### For Consistent Results:

1. **Always attach the previous level** as a reference image when generating the next
2. **Use hex color codes** - "#FFB6C1" is more consistent than "pink"
3. **Describe proportions as ratios** - "snout is 40% of face height"
4. **Name specific art influences** - "style of Clash Royale characters" or "Supercell game art style"

### Platform-Specific Tips:

**OpenAI/DALL-E:**
- Explicitly state "PNG with transparent background" at the start
- Reference previous outputs by uploading them as context

**Midjourney:**
- Use `--sref [URL]` (style reference) with your approved Level 1 image
- Add `--no background` to help with transparency
- Use `--style raw` for more literal interpretation

**Stable Diffusion:**
- Use ControlNet with your base image for pose consistency
- Enable "transparent background" in generation settings
